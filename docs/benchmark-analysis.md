# 10M+ clicker / idle benchmark synthesis

The product target is not a clone. It combines proven retention loops from high-scale incremental games with a new theme, visual identity and economy.

## Benchmarks used
- Tap Titans 2 — 10M+ Google Play downloads: immediate tap combat, staged unlocks, hero/collection layers, tournaments/social meta, prestige.
- Egg, Inc. — 10M+: tactile core action plus visible simulation, capacity balancing, research, prestige and strong visual growth.
- AdVenture Capitalist — 10M+: business ladder, automation, exponential scaling, manager unlocks, event cadence.
- Idle Miner Tycoon — 100M+: layered production system, managers/boosts, offline earnings, location progression and optimization.

## Extracted fun pillars
1. **Immediate agency** — every tap visibly pays out in under 100 ms.
2. **Automation handoff** — manual input gets the first dopamine hit, then machines create relief and compounding growth.
3. **Frequent breakpoints** — costs, ownership milestones, contracts and unlocks ensure a short goal is almost always visible.
4. **Exponential spectacle** — numbers and visuals both escalate; the world should look richer as income grows.
5. **Prestige with meaning** — reset is voluntary, previewed and grants permanent power instead of feeling like lost work.
6. **Return value** — offline earnings make reopening rewarding without requiring constant play.
7. **Interruption rewards** — lucky comet and timed Pulse break passive watching with a high-value action.
8. **Collection/permanence** — relic upgrades create a durable meta layer beyond the current run.
9. **Rhythm mastery** — combo adds light skill expression without undermining idle accessibility.
10. **Mobile comfort** — one-thumb core action, large hit targets, short labels, safe-area UI and installable PWA behavior.

## What Lumen Loop deliberately does differently
- No copied characters, business names, UI layouts, art, economy values or narrative.
- A single pocket-star scene visually accumulates orbiting machines rather than using a list-only presentation.
- Combo + Pulse + Comet create three distinct tempos: continuous tapping, planned burst, surprise burst.
- Stardust can be spent on relics while `totalStardust` preserves the prestige power already earned.
